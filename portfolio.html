About

I'm a Computer Science & Statistics student at the Faculty of Science, Alexandria University, currently training in Full-Stack .NET development through DEPI (Digital Egypt Pioneers Initiative). I started with front-end development — HTML, CSS, and JavaScript — because I wanted to see immediate, visual results from my code, and that curiosity pulled me deeper into how the web works end-to-end.

When I build something, I care most about two things: that it works correctly on every screen size, and that the code stays readable enough for someone else — or future me — to pick up and understand. I'm currently expanding into ASP.NET Core and C# to build complete, full-stack applications.

نبذة عني

أنا طالبة في قسم علوم الحاسب والإحصاء بكلية العلوم، جامعة الإسكندرية، وبتدرب حاليًا على Full-Stack .NET Development من خلال برنامج DEPI (مبادرة رواد مصر الرقمية). بدأت رحلتي بتطوير الواجهات الأمامية — HTML وCSS وJavaScript — لأني حبيت أشوف نتيجة فعلية وبصرية لأي كود بكتبه، وده اللي شدّني أعرف أكتر إزاي الويب بيشتغل من الألف للياء.

لما بكتب كود، بهتم بحاجتين قبل أي حاجة: إن الموقع يشتغل صح على أي مقاس شاشة، وإن الكود يفضل واضح بحيث أي حد تاني — أو أنا نفسي بعد فترة — يقدر يفهمه ويكمل عليه بسهولة. دلوقتي بوسّع مهاراتي في ASP.NET Core وC# عشان أقدر أبني تطبيقات متكاملة (Full-Stack).
